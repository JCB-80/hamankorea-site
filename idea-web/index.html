영상의 기준은 하나, “바이브코딩할 때 참고하고 싶은 정도”.

흑백 점프 플레이아케이드 게임 10종작업방

제작
노트

  1. 01

    아이디어와 동작만 가져왔습니다

    로고, 화면 디자인, 사이트에 적힌 문구는 원본 회사의 것입니다. 이 페이지는 같은 기능을 새로 구현한 오마주이며, 원본과 연결되거나 제휴된 페이지가 아닙니다.

  2. 02

    설치도, 서버도, 계정도 필요 없습니다

    모두 브라우저에서 도는 정적 페이지입니다. 데이터는 서버로 보내지 않고, 기록이 필요한 곳은 브라우저 저장소에만 남깁니다.

  3. 03

    원본이 AI를 쓰는 곳은 간이 모델로

    꼬맨틀의 유사도, 인피니트 크래프트의 조합, 퀵 드로우의 필기 인식은 브라우저에서 도는 작은 규칙·모델로 대신했습니다. 원본과 결과가 정확히 같지는 않습니다.

실행
안내

  1. 01

    가장 빠른 방법

    D:\shinbak-lab\index.html 파일을 브라우저로 열면 바로 실행됩니다. 인터넷이 없으면 글꼴만 기본 글꼴로 바뀌고 기능은 그대로 동작합니다.

  2. 02

    로컬 서버로 열기

    폴더에서 python -m http.server 8123 를 실행한 뒤 http://localhost:8123 을 열어도 됩니다. 저장 기능을 쓰려면 이쪽이 더 안정적입니다.

  3. 03

    바로 가기

    ⌘K 로 검색, Esc 로 닫기. 주소 끝에 #/a/pointer 처럼 앱 이름을 붙이면 바로 열립니다.

신박랩은 혼잡스의 영상 「신박한 웹사이트 티어표」에서 소개된 사이트들의 아이디어를 참고해 만든 개인 프로젝트입니다. 원본 사이트와 제휴 관계가 없으며, 상표와 디자인은 각 소유자에게 있습니다.
